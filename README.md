# Python IP Locator

A simple Python tool that retrieves geolocation information about an IP address using the [ipwho.is API](https://ipwho.is/).

## ✨ Features
- IP address lookup
- City, region and country
- Latitude and longitude
- Postal code and timezone
- Error handling

## 🛠️ Requirements
- Python 3
- `requests` library

## 🚀 Installation

```bash
pip install requests
```

## 💻 Usage

Run the program:

```bash
python main.py
```

Enter an IP address when prompted.

## ⚠️ Note
IP geolocation is approximate and does not provide an exact physical location. Private IP addresses cannot be reliably geolocated using public IP lookup services.
